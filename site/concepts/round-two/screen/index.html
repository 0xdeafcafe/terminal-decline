Pin a command to the Dock

A pin gives a command its own Mac app, with its own icon, windows and settings. It uses the program’s own icon when there is one, otherwise it draws one.

decline pin rush --dock

Needs rush installed. Pin options.

Generated pin icons, not the installed rush icon.

Terminals for agents

Run programs in headless terminals. Type into them, wait on them and read the screen back as text or JSON, with cells, colours and cursor.

ctl reference

decline ctl spawn --name sh --shelldecline ctl send sh --text "make test" --key enterdecline ctl wait-for sh --command --timeout 600000decline ctl screen sh --jsondecline ctl kill sh

Tab completion explains flags and subcommands from man pages and --help. Completion as you type, output colouring and copy on select are opt-in.

Install

Releases are for Apple Silicon and need macOS 14 Sonoma or later.

brew install --cask 0xdeafcafe/tap/terminal-decline

Installs Terminal Decline.app and the command as terminal-decline and decline.
