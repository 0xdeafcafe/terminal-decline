Terminals for agents

decline ctl runs programs in real Decline terminals without windows. An agent can type, wait for a command to finish and read the screen back as text, or as JSON with cells, colours and cursor. With no window open it starts a headless server with no Dock icon, which leaves once idle.

decline ctl spawn --name sh --shell
decline ctl send sh --text "make test" --key enter
decline ctl wait-for sh --command --timeout 600000
decline ctl screen sh --json
decline ctl kill sh

Agent API reference

A command of its own in the Dock

A pin makes a command its own Mac app, with its own icon, windows and settings. Pins load the installed app, so they keep working after updates.

decline pin rush --dock

Needs rush installed. Uses the program’s own icon if it ships one, otherwise draws one like these. Pin options

Tab explains the flags

Completions come from zsh, with descriptions from man pages and --help. Completion as you type is opt-in.

Install

brew install --cask 0xdeafcafe/tap/terminal-decline

Installs Terminal Decline.app and the command as terminal-decline and decline. macOS 14 Sonoma or later. Releases are for Apple Silicon. Build from source
