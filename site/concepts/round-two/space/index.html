How it was measured

Each terminal runs from its own config in a temporary folder, one window, 100 by 30 cells, Menlo 13. Memory is the macOS physical footprint summed over the terminal's processes, read with footprint rather than RSS. The cat is a 100 MB file of coloured log lines, timed as the shell sees it. Runs interleave the terminals so a busy Mac (load 3 to 6) hits them alike. Decline at 7849ad4, Ghostty 1.4.0, kitty 0.49.2. The script is scripts/compare/run.py; the table is in the README.

CPU for the cat, WindowServer included: Decline 0.66 s, Ghostty 2.04 s, kitty 1.63 s. Warp and Terminal.app, measured the same way on 30 October, took 3.6 s and 4.0 s.

On 30 October Ghostty won the cat wall time, 0.53 s to Decline's 0.61 s, with Decline at 31.5 MB idle and Ghostty 67 MB. That run had 4 runs each and is kept apart in its own page. Input latency has not been measured. Idle CPU is low, not zero.

Pin a command to the Dock

Any command can be its own Mac app, with its own icon, windows and settings. decline pin rush --dock makes rush.app in your Applications folder and puts it in the Dock; clicking it opens a Decline window running rush and nothing else.

The icon is the program's own if it ships one. Otherwise one is drawn: a large initial and the mint Slope on a hue picked from a fixed palette by the name. Pins load the installed app, so they keep working after an update.

decline pin rush --dock
decline pin Rush --icon rush.png --cwd ~/code -- rush
decline pin --list
decline pin --edit rush

Real terminals for agents and tests

decline ctl runs programs in real Decline terminals without windows. An agent can type into one, wait for a command to finish, and read the screen back as text or as JSON with every cell, colour and the cursor. A headless server starts when needed, talks over a socket only your user can reach, and leaves once idle.

# a shell session: run make test and wait for it to finish
decline ctl spawn --name sh --shell
decline ctl send sh --text "make test" --key enter
decline ctl wait-for sh --command --timeout 600000
decline ctl screen sh --json
decline ctl kill sh

# a program at a fixed size, then a GPU screenshot in your theme
decline ctl spawn --name top --size 100x30 -- htop
decline ctl wait-for top --text "Load average" --timeout 5000
decline ctl screenshot top top.png
decline ctl kill top

Example commands from the documentation; no session output is shown. Each command prints one line of JSON. Agent API design.

Tab says what the flag does

Tab shows zsh's matches in a list with what each flag or subcommand does, taken from its man page or --help. Grey text after the cursor shows the rest of the first match and Right takes it. Completion as you type, coloured output and copy on select are off until you turn them on.

Install

brew install --cask 0xdeafcafe/tap/terminal-decline

Apple Silicon, macOS 14 Sonoma or later. The cask installs Terminal Decline.app and the command as both terminal-decline and decline. To build from source, or to install the bare command with cargo, see the README. Settings live in ~/.config/terminal-decline/config.toml and reload when they change.
